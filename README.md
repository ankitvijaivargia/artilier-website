# Artilier — website

Production source for **artilier.co** (`www.artilier.co` redirects to it).

Artilier is a design-led studio in New Delhi working through art, material and
making. The current collection is rugs: hand-knotted, hand-tufted and flatweave,
made to order in any dimension.

---

## Technology

Plain static HTML, CSS and vanilla JavaScript. No framework, no bundler, no
package manager, no build step, no runtime dependencies. The two brand fonts
(Cormorant Garamond, Jost) are self-hosted in `assets/fonts/` (`assets/css/fonts.css`);
nothing loads from Google Fonts. While they load, text is set in metric-matched
local fallbacks so the page does not shift when they arrive — those `@font-face`
rules are generated by `tools/font_fallbacks.py` (see its header before editing
fonts, stylesheets or large amounts of copy).

## Brand tokens (source of truth: `assets/css/base.css`)

| Role | Token | Value |
| --- | --- | --- |
| Display serif (headings) | `--d` | Cormorant Garamond (300/400/500, italic 300/400) |
| Sans (body, labels, UI) | `--s` | Jost (300/400/500) |
| Ground | `--paper` / `--bone` / `--stone` / `--sand` | `#F7F3EB` / `#EFE8DC` / `#DDD3C2` / `#C9BCA6` |
| Text and dark grounds | `--ink` (= `--tx`) / `--espresso` / `--chocolate` | `#151110` / `#241C16` / `#3E2E22` |
| Secondary text | `--tx-2` / `--tx-3` | `#5C5044` / `#8A7C6C` |
| Accents | `--rust` / `--rust-d` / `--brass` / `--brass-l` / `--olive` | `#A04A29` / `#7E3820` / `#A98B4E` / `#C4A667` / `#4A4F3C` |

Fonts load from Google Fonts (`Cormorant+Garamond` and `Jost`). Tenor Sans, DM Mono,
Instrument Serif, `#b8923a` and `#f4efe6` are not used anywhere in the site.
On dark sections use paper or `--brass-l` for text and accents; rust on espresso is 2.8:1.

## Running locally

Any static server; the pages use root-relative paths (`/assets/…`), so opening
the files directly with `file://` will not resolve them.

```bash
python3 -m http.server 8080     # then open http://localhost:8080
# or
npx serve .
```

## Building

Pages under `collection/`, `bespoke/`, `trade/`, `materials/`, `process/`,
`craft/`, `contact/`, `about/`, `projects/`, `hospitality/`, `fr/`, `guides/` and
`404.html` are **generated** from `/content` by the scripts in `tools/`. Edit the
generator (or the content), never the generated HTML, then run:

```bash
python3 tools/og.py          # social preview images for design pages (needs Pillow)
python3 tools/images.py      # responsive variants in assets/media/r/ + manifest w/h (needs Pillow); run after adding photographs
node tools/build.mjs         # design and category pages
node tools/build2.mjs        # bespoke, trade, materials, process, craft; collection hub
node tools/build3.mjs        # contact, about, projects, hospitality, market pages, /fr/, guides, 404,
                             # shared shell for collaborations + collection hub, homepage footer, sitemap
python3 tools/check.py       # links, metadata, schema, sitemap, discretion checks — must print OK
```

After a release, the **SEO monitor** workflow (`.github/workflows/seo-monitor.yml`,
weekly and on demand) crawls the live site with `tools/seo_monitor.py`, runs
Lighthouse on key pages and confirms the live HTML matches `main`; its report is
posted to the "SEO monitor" issue. See `SEO_OPERATING_SYSTEM.md`.

`index.html` and `collaborations/index.html` are hand-maintained; `build3.mjs`
keeps their navigation, footer and Organization schema in sync. `tools/` is
excluded from deployment by `.assetsignore`.

## Deployment — Cloudflare Workers (static assets)

The site is served by a Cloudflare Worker with static assets (`wrangler.jsonc`:
`assets.directory = "."`, `not_found_handling = "404-page"`). Pushes to `main`
deploy automatically; work on a branch and merge through a pull request.
`_headers` and `_redirects` are applied by the assets runtime.
